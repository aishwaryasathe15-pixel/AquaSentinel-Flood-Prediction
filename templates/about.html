PROJECT OVERVIEW

AI-Based Flood Risk Prediction & Early Warning Website

A web application for learning how historical environmental observations can be used to classify estimated flood risk.

Methodology
  1. Collect labelled historical observations.
  2. Clean missing and invalid values.
  3. Train a Random Forest classifier.
  4. Evaluate using a hold-out test set.
  5. Predict a risk category for new inputs.
  6. Show visual analytics and general guidance.
Model inputs
  • Rainfall (mm)
  • Water level (m)
  • Humidity (%)
  • Temperature (°C)
  • Elevation (m)
  • Previous flood occurrence (0/1)
Safety disclaimer: This is an academic prototype, not a validated operational forecasting system. The demo data is synthetic. Never rely on this website for evacuation or emergency decisions; follow official local authorities and meteorological/hydrological services.
